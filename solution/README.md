# Answer key

These two files are the finished answers. They are only here so the demo can be shown without a coding agent, or so you can check your work.

- `answer-tests.js` is a correct `tests/contract.test.js`. Copy it into place with `npm run answer:tests`.
- `answer-code.js` is a correct `src/trashRobot.js`. Copy it into place with `npm run answer:code`.

If you are using Claude Code, do not look at these until you have finished. The point of the exercise is to watch the tests get written from the spec.
